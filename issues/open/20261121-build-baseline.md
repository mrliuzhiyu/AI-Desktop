# 构建基建基准

日期：2026-11-21
状态：实现中

参考 TEXTVIEW 的版本契约、独立 CI、文档治理与可验证验收机制，适配原生动画工具。

## 验收标准
- [ ] main 为唯一分支，34 个实际内容提交，项目级通用提交身份，无远端。
- [ ] Windows 两组件构建与安装包完整性验证通过。
- [ ] 脚本、版本、配置、文档与隐私检查可本地执行。
- [ ] CI 覆盖 main、PR 与 macOS；结果作为附件，不提交结果分支。
- [ ] 发布标签与版本一致，产物附 SHA-256。
- [ ] 明确标注未执行的 macOS、GUI 安装与远端 CI 检查。
